# Expanded navigation acceptance

Read for suite-navigation review. A well-styled closed header cannot pass on behalf of its undisplayed states.

Compare equivalent desktop and phone reference/candidate states at equal viewport and native detail. Open the richest panel, one differently shaped panel, keyboard focus, phone root and phone category. Inspect header attachment, column measures, type hierarchy, edge weight, secondary media crop and whether the page remains visually subordinate.

Record evidence → contract → rendered component/state → viewed capture/test. Missing expanded navigation is a structural gap, not deferred micro-polish. State what is research-only versus implemented.

## Behavioural gates

- Fine pointer opens deliberately; explicit activation is immediate; trigger-to-panel travel remains usable. Probe near/far diagonals, brief crossing, leave/re-entry and rapid category reversal. Record coordinates before interpreting a failure.
- Only one category is logically active. Exiting links cannot be focused/clicked. Resizing height does not stretch text. Timers cannot reopen dismissed content or close a newer selection.
- Disclosure semantics, Enter/Space, Tab/Shift+Tab, Escape, outside dismissal and focus return behave predictably. Test fresh keyboard contexts without hover contamination; check actual activeElement.
- Phone root/category/Back/Close retain all essential routes and account actions. Last links cannot hide behind the footer. Scroll containment, short heights, safe areas, resize and restoration are checked. Do not mistake unsupported browser-driver gestures for site defects.
- Reduced-motion initial/live changes eliminate unnecessary translation without hiding destinations. Failed media, delayed fonts and no-JavaScript leave a usable discovery route.
- Audience switching closes safely, preserves a sensible focus target/history, and changes the intended descriptions/proof without silently removing capabilities.
- All destinations resolve to the promised task. Documentation fallback is labelled; preview/availability restrictions remain visible. No empty href, invented plans or account-activation promises.

Separate visual, interaction, content/destination and device coverage findings. Famous references can have weaknesses worth rejecting. Browser automation is not a screen-reader or physical-device certification. Mark unavailable checks pending, not passed.
