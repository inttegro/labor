# Marketing Product Media

Treat media as evidence with an editorial job. Read [media direction](references/media-direction.md), [format selection](references/format-selection.md) and [scene engineering](references/scene-engineering.md). Choose and defend the presentation format yourself; do not wait for the user to request a gallery, loop, film or scroll sequence.

Before sourcing/generation specify claim, subject, composition, focal point, UI/text, aspect ratios/mobile crop, rights, provenance and fallback. Reject beautiful media that teaches the wrong category.

Use authorized authentic UI where practical. Recompose only to clarify; preserve vocabulary, state logic and meaningful values. Clearly labelled fictional demos may illustrate simulated outcomes. Never present those outcomes as real money movement, actual execution evidence, or proof that an unverified capability is available.

Specify motion as states and transitions, not “smooth animation.” Produce a storyboard and implementation contract before code. Choose DOM/SVG/image/video/canvas by information and interaction needs.

For connected, multi-step demonstrations, read [the worked scene contract](references/worked-scene.md), including persistence, interruption and acceptance cases.

Review actual display-size crops, motion, poster, pause, loading and reduced motion. Use the applicable image-generation skill/tool if raster generation is appropriate; this skill doesn't replace it.
